# Offsite / leadership callout — coding-agent Gateway economics

Use when drafting leadership, GTM, or enablement content. Keep internal.

## One-slide line

> **We are winning the metering argument and losing the commercial frame.**  
> Customers comparing Claude Code Max/Team to Unity AI Gateway pay-per-token will often conclude “Databricks is more expensive.” That can be true for a heavy seat and still the wrong bake-off. Decks sell governance; they do not arm the field for this objection.

## Why it matters

| Signal | Detail |
| --- | --- |
| Recurring POC pattern | Claude Code “In” ≪ Gateway input; output similar; $ looks multi-× |
| Technical truth | API list parity; cache discounts often already in Gateway $ |
| Commercial truth | Max/Team can beat PPT for power users |
| Field-materials gap | Battlecard / L200 / product deck = upside only; no Max-vs-PPT slide |
| Strategic risk | Coding-agent Gateway is a headline motion; FinOps can kill POC early |

## Asks

1. Endorse frame: **governance + API list parity**, never “cheaper Max” (AI Governance PM + GTM)
2. Ship battlecard addendum: Max vs PPT + metering reconciliation (PMM / FE enablement)
3. Standardize POC kit: four-rate SQL + Claude Code PPT cost estimator (FE / Solutions)
4. Decide PPT-only vs seat-like economics for coding agents (Leadership)
